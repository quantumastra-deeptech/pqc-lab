          QUICK REFERENCE
          
The 4 Migration Rules.
What changes and what stays unchanged.

        

        
Never assume all cryptography must be thrown away. Asymmetric public-key schemes are replaced; symmetric 256-bit ciphers are retained.

      


      

        

          
RULE 01 · ASYMMETRIC SIGNATURES

          
RSA-PSS / ECDSA → ML-DSA-65

          
Signatures proof of authorization. Replaced with NIST FIPS 204 module-lattice signatures. Signature size expands from 256 B to 3,309 B (~12.9×).

          
FIPS 204 · Category 3 Security

        


        

          
RULE 02 · ASYMMETRIC ENCRYPTION

          
RSA-OAEP → ML-KEM-768 + AES-GCM

          
Do not encrypt large data directly with lattices! Use ML-KEM-768 to establish a shared secret, then use authenticated symmetric encryption for the field.

          
FIPS 203 · Category 3 Security

        


        

          
RULE 03 · SYMMETRIC CIPHERS

          
AES-256-GCM is RETAINED

          
Grover's quantum algorithm halves key space from 256 to 128 bits. 128-bit security remains computationally unbreakable. No migration needed.

          
NIST SP 800-38D · Quantum Safe

        


        

          
RULE 04 · TRANSPORT & TLS

          
TLS 1.3 adopts Hybrid X25519MLKEM768

          
Combines classical Curve25519 with ML-KEM-768. Protects against Harvest-Now-Decrypt-Later (HNDL) without breaking legacy TLS middleboxes.

          
IETF Draft · Chrome & Cloudflare Active
