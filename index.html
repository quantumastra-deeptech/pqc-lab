size and a shape.

Post-quantum algorithms change more than the math. They can change key sizes, signature sizes, network payloads and operational requirements.

WHY IT MATTERS

Plan for API payload limits, database columns, message queues, logs, latency and bandwidth. Cryptographic migration is also an engineering and operations project.

FIELD ENCRYPTION / FIPS 203

Don't encrypt a
large message with
a tiny key.

Use a Key Encapsulation Mechanism (KEM) to establish a shared secret, then use authenticated symmetric encryption for the actual data.

DESIGN PATTERN / 04

Keep crypto out
of business logic.

The controller should express intent — sign this payment, protect this field. The provider owns the algorithm-specific implementation.

THE IMPORTANT DIFFERENCE

Before: algorithm in every route.

Controllers know which primitive to call. A migration touches many files and increases the chance of inconsistent changes.

AFTER: intent in every route.

After: one provider seam.

Controllers depend on a stable interface. Implementations and policy can evolve behind it, with explicit configuration and tests.
